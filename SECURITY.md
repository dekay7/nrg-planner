# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Use GitHub's **Report a
vulnerability** option on the repository's Security page when it is available.
If private vulnerability reporting is not enabled, open an issue containing only
a request for a private reporting channel. Do not identify the affected feature or
include exploit details, credentials, household configuration, or personal data in
a public issue.

Include the affected version or commit, the impact, and steps to reproduce using
invented data. The maintainer will acknowledge and assess reports as availability
permits; there is no guaranteed response or remediation timeframe or bug bounty.

## Supported versions

Security fixes are made against the latest source on the default branch. Older
versions may not receive fixes; update to a reviewed current release where possible.

Please do not test against another person's Home Assistant installation, devices,
accounts, or data.
